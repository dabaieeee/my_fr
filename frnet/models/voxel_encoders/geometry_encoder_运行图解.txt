================================================================================
                        关键算法：法向量计算
================================================================================

对于点 p_i 及其k个邻居点：

步骤1: k-NN搜索
    ┌─────┐
    │ p_i │ ← 中心点
    └──┬──┘
       │
       ├──→ p₁ (最近)
       ├──→ p₂
       ├──→ ...
       └──→ pₖ (第k近)

步骤2: 计算局部坐标系
    centered = [p₁-p_i, p₂-p_i, ..., pₖ-p_i]  # [k, 3]

步骤3: 协方差矩阵
    Cov = (centeredᵀ × centered) / k  # [3, 3]

步骤4: 特征值分解
    Cov = Q × Λ × Qᵀ
    其中：
    - Λ = diag(λ₁, λ₂, λ₃)  # 特征值，λ₁ ≥ λ₂ ≥ λ₃
    - Q = [v₁, v₂, v₃]      # 特征向量

步骤5: 法向量
    normal = v₃  # 最小特征值对应的特征向量

几何意义：
    • λ₁ 最大 → 主方向（沿表面）
    • λ₂ 中等 → 次方向（沿表面）
    • λ₃ 最小 → 法向量方向（垂直于表面）


================================================================================
                        关键算法：曲率特征计算
================================================================================

基于协方差矩阵的特征值 λ₁ ≥ λ₂ ≥ λ₃：

线性度 (Linearity):
    L = (λ₁ - λ₂) / λ₁
    • L → 1: 点沿一条线分布（如电线、栏杆）
    • L → 0: 点不呈线性

平面度 (Planarity):
    P = (λ₂ - λ₃) / λ₁
    • P → 1: 点在一个平面上（如墙面、地面）
    • P → 0: 点不在平面上

球面度 (Sphericity):
    S = λ₃ / λ₁
    • S → 1: 点呈球形分布（如球体、圆柱）
    • S → 0: 点不呈球形

示例：
    ┌─────────────┬──────────┬──────────┬──────────┐
    │   形状      │  线性度  │  平面度  │  球面度  │
    ├─────────────┼──────────┼──────────┼──────────┤
    │   电线      │   ~1.0   │   ~0.0   │   ~0.0   │
    │   墙面      │   ~0.0   │   ~1.0   │   ~0.0   │
    │   球体      │   ~0.0   │   ~0.0   │   ~1.0   │
    │   圆柱      │   ~0.5   │   ~0.0   │   ~0.5   │
    └─────────────┴──────────┴──────────┴──────────┘


================================================================================
                        数据维度变化示例
================================================================================

假设：N=1000个点，启用法向量和曲率

输入:
    voxels: [1000, 4]  (xyz + intensity)
    coors:  [1000, 4]

提取xyz:
    xyz: [1000, 3]

计算法向量:
    normals: [1000, 3]

计算曲率:
    curvature: [1000, 3]

特征拼接:
    geo_input = concat([xyz, normals, curvature])
    → [1000, 9]

MLP处理:
    [1000, 9]  → Layer 1 → [1000, 64]
    [1000, 64] → Layer 2 → [1000, 128]
    [1000, 128] → Layer 3 → [1000, 128]

点级别输出:
    geo_point_feats: [1000, 128]

视锥级别聚合 (假设M=500个视锥):
    geo_voxel_feats: [500, 128]
    geo_voxel_coors: [500, 4]


================================================================================
                        设计要点
================================================================================

1. 小感受野 (k=10)
   ┌─────────────────────────────────────┐
   │  只关注局部几何结构，避免语义污染    │
   └─────────────────────────────────────┘

2. 结构保持
   ┌─────────────────────────────────────┐
   │  使用 max pooling 而非 mean pooling  │
   │  保持几何特征的显著性                │
   └─────────────────────────────────────┘

3. 几何专注
   ┌─────────────────────────────────────┐
   │  只处理几何信息（xyz, 法向量, 曲率） │
   │  不涉及语义或上下文信息              │
   └─────────────────────────────────────┘

4. 可配置性
   ┌─────────────────────────────────────┐
   │  • with_normals: 是否计算法向量      │
   │  • with_curvature: 是否计算曲率      │
   │  • k_neighbors: 邻居点数量            │
   └─────────────────────────────────────┘
